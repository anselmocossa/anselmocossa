# Anselmo Cossa

Analista de Sistemas na **Empresa Nacional de Hidrocarbonetos, E.P. (ENH)**, Moçambique, desde 2021. Actuação na gestão do SAP S/4HANA e do SAP SuccessFactors, na integração entre sistemas, na administração de bases de dados e no desenvolvimento de aplicações empresariais para as 10 empresas do Grupo ENH.

## Áreas de actuação

**SAP S/4HANA e SAP SuccessFactors**
- Suporte funcional e técnico aos sistemas em produção (RISE with SAP, Private Edition), com cerca de 300 utilizadores SAP e 400 colaboradores
- Gestão de autorizações e perfis para as 10 empresas do grupo
- Configuração de workflows de aprovação de requisições, pedidos de compra e facturas
- Autenticação única (SSO) com Microsoft 365, através do SAP Identity Authentication
- Desenvolvimento ABAP e de aplicações SAP Fiori

**Integrações e APIs**
- Serviços OData no S/4HANA para o sistema de venda de gás natural: factura em PDF, extracto de conta corrente e compensação automática de facturas
- Integração das picagens biométricas com o SuccessFactors Time Management, através do SAP Integration Suite e de API com autenticação OAuth2
- Sincronização diária de dados entre o SuccessFactors e o Portal do Colaborador

**Administração de bases de dados**
- SQL Server, MySQL/MariaDB e PostgreSQL, em servidores locais e na AWS
- Rotinas de cópia de segurança, testes de reposição, migrações e recuperação de dados
- Data warehouse em SQL Server para relatórios de gestão em Power BI

**Desenvolvimento de aplicações**
- Portal de Fornecedores da ENH, com registo, qualificação e concursos electrónicos para mais de 1.500 fornecedores
- Portal do Colaborador, Portal de Recrutamento e sistema de venda de gás natural
